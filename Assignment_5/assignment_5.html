INTERPRETATION: Running Agnes With Four Linkage Methods

Hierarchical clustering is performed according to four different linkage options to see how each cereal is grouped.

  • Single linkage: In single linkage clustering, clusters are formed from the closest pair of points, giving rise to chain-like clusters.

  • Comple Linkage: Complete linkage uses the two most distant points in each cluster, producing compact clusters.

  • Average Linkage: Average linkage is determined using the mean distance between two clusters and is more balanced.

  • Ward’s Method: Ward’s method, which minimizes total within-cluster variance, usually produces compact and tightly bounded clusters.

This makes it possible to compare and determine the best method for modeling this particular dataset.

The agglomerative coefficient describes the fit of a set of clusters within the data. High values indicate clusters have greater compactness and separation. The method which produces the highest AC is preferred, showing that the groups are most clearly defined within the cereal data.
